### **Рекомендации:**
1. **Шампунь:**  
   - Шампунь для комбинированного типа волос (жирные корни и сухие концы).  
   - С мягкими очищающими компонентами (например, алоэ вера или ромашка).  

2. **Кондиционер:**  
   - Увлажняющий кондиционер для сухих волос, наносить только на длину и концы.  
   - Избегать попадания на корни.  

3. **Дополнительный уход:**  
   - Использовать восстанавливающие маски для пористых волос 1–2 раза в неделю (с маслами, кератином, протеинами).  
   - Применять несмываемые антифриз-средства (кремы или сыворотки).  
   - Использовать термозащиту при укладке феном или плойкой.  

4. **Для кожи головы:**  
   - Регулярно очищать мягким шампунем, подходящим для нормальной кожи головы.  
   - Раз в месяц использовать скраб для кожи головы для глубокого очищения.
