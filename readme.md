Этапы работы приложения.

Надо установить библиотеку для эмодзи:

```
cd emojipy
python setup.py install
```

Может понадобиться:
```
git clone https://github.com/launchyard/emojipy.git
```

Шаг 1. Парсинг данных.
Чтобы начать парсить данные, необходимо:
1) открыть таблицу с определенной категорией, например, "Шампуни", лист "Средства".
Столбец "Ссылка в Золотом Яблоке".
Вставляем новые ссылки на средства (по 1ой в каждую ячейку)
и в столбце "Новое" пишем "да".
Сохраняем. Закрываем таблицу.

Нажимаем на ui - кнопку "парсинг".

Шаг 2.
Заполняем данные о пользователе. Средства -> Подборки. Сохранить.

Шаг 3.
Собираем данные из таблицы, вставляем в промпт, отправляем в GPT.
Нажимаем на ui - кнопку "Анализировать".

Шаг 4. Разбираем данные от GPT. Наполняем таблицу "Подборки".
