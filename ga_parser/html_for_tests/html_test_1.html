Профессиональный бренд для волос Matrix основал американский парикмахер Арни Миллер.

В 1980 году, когда ему пришла идея бренда Matrix, он работал стилистом уже 20 лет и отлично понимал потребности профессионального рынка. Он создал простые в применении и эффективные в действии продукты для всех типов и потребностей волос.

Эффективные формулы, простая навигация по гаммам, яркий дизайн – у Matrix есть все, чтобы упросить подбор правильной профессиональной рутины для волос.

В ассортименте уходов Matrix есть гаммы для объема от корней, для окрашенных волос, включая бессульфатные шампуни, гаммы для увлажнения сухих и кудрявых волос, синие и фиолетовые шампуни для поддержания блонда, гаммы для гладкости и шелковистости, а также продукты для секущихся и ломких волос. Уходы от Matrix – это профессиональные шампуни, кондиционеры и несмываемый уход (масла, маски, спреи или крема для волос).
